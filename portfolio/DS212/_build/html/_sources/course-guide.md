# How to use this book

This is your reading and practice companion for **DS212 — Object-Oriented Programming**. Work through the lessons in order, or use the navigation to revisit a topic.

## Find your way

- **Course navigation** on the left lists lessons by topic. Exercises sit directly below their related lesson. On a small screen, use the menu button to open it.
- **On this page** lists headings within the current lesson. Use it to jump to a section without losing your place in the course.
- **Search** finds terms across the book, including code and exercises.
- **Previous and next** links at the bottom follow the reading order, including practice activities.

## Your learning path

1. Start with [Programming paradigms](notebooks/00_Introduction.ipynb), then try [Identify the paradigm](notebooks/exercises/00_Exercise.ipynb).
2. Read [History and principles of OOP](notebooks/01_History.ipynb), then work through [Thinking in objects](notebooks/exercises/01_Exercise.ipynb).
3. Revisit [Python review I](notebooks/02_PythonReview1.ipynb) and [Python review II](notebooks/03_PythonReview2.ipynb).
4. Apply both reviews in the [Python coding exercise](notebooks/exercises/02_Exercise.ipynb).

## Read, experiment, reflect

Read the explanation, predict what an example will do, then run and modify it in your own notebook. The website displays notebook content; to execute Python, download the notebook from the page toolbar and open it in Jupyter.

For exercises, write down your reasoning as well as your answer. Return to the related lesson when you need a reminder.

```{tip}
Use the theme button in the toolbar to switch between light and dark reading modes. Full-screen mode gives long examples more room.
```
