Datasets

Datasets#

The lessons, seatworks, and activities use the files below. Download them into a folder named data next to your notebook so that paths such as data/grades.csv work.

File

Used in

Description

grades.csv

files, NumPy, pandas

36 students, 4 sections, quiz/lab/midterm/final scores, with a few missing values (synthetic)

menu.csv

pandas

canteen menu: item codes, names, categories, prices (synthetic)

canteen_sales.csv

pandas

one month of canteen order lines for two branches (synthetic)

weather.csv

pandas

daily temperature, rainfall, and humidity for three stations (synthetic — not real observations)

advertising_synthetic.csv

revisiting paradigms

TV advertising budget vs. sales for 200 markets (synthetic, modeled on the ISLR Advertising data)

reviews.csv

dictionaries, text data

10,000 hotel review texts (provided with the course materials)

sample_data.xlsx

reading Excel files

loan-application toy dataset (provided with the course materials)

Note

The synthetic datasets were generated with a fixed random seed for teaching purposes. They do not describe real students, businesses, or weather.
