Assignment 3: Functions and Collections#

DS112 — Computer Programming

Assessment: Assignment 3 · Week 7 · CO2

ILO : Define and call user-defined functions; create data structures and differentiate their advantages and disadvantages.

Overview#

Build a small student records toolkit made of well-documented functions that operate on lists, tuples, dictionaries, and sets. Design the program procedurally: each function has one responsibility, and a short main() uses them.

Data#

Start from this list of records (you may add more):

records = [
    ("2026-001", "Ana Cruz", "DS1A", [88, 92, 95, 79]),
    ("2026-002", "Ben Reyes", "DS1B", [75, 70, 80, 68]),
    ("2026-003", "Carlo Santos", "DS1A", [91, 85, 89, 94]),
    ("2026-004", "Diana Lim", "DS1C", [62, 70, 58, 66]),
    ("2026-005", "Ella Garcia", "DS1B", [80, 84, 90, 87]),
    ("2026-006", "Felix Tan", "DS1C", [70, 73, 77, 81]),
]

Required Functions#

Each function needs a docstring and must return its result (no printing inside, except main()).

Function

Returns

average(scores)

the mean of a list of scores

letter(avg)

"A", "B", "C", or "F" (90 / 80 / 75 cut-offs)

to_dicts(records)

a list of dictionaries with keys id, name, section, scores

index_by_id(students)

a dictionary id → student

by_section(students)

a dictionary section → list of names

ranking(students)

a list of (name, average) tuples sorted from highest to lowest

common_sections(a, b)

the set of sections shared by two lists of students

initials(name)

"Ana Cruz" → "A.C."

summary(students)

a dictionary with count, class_average, passed, failed

Use at least one list comprehension, one dictionary comprehension, one lambda, and one of map/filter.

main()#

Write a main() that prints a neat report: the ranking table with letter grades and initials, the sections and their members, and the summary.

Reflection (Markdown)#

  • Explain why you used each data structure (list, tuple, dict, set) where you did — include a table of advantages and disadvantages.

  • Which of your functions are pure? Which one was hardest to write, and why?
