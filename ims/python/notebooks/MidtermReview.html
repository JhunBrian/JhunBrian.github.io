Midterm Review Guide#

DS112 — Computer Programming

Week 9: · Midterm Examination Week

This page summarizes the topics from Weeks 2–8 and gives you questions to check your own understanding. It does not contain actual examination items.

Self-Check Questions#

Concepts#

  1. What is the difference between a compiler and an interpreter? Which is Python, and what is bytecode?

  2. List Knuth’s five properties of an algorithm and give a non-example for two of them.

  3. Explain structured, procedural, and functional programming, each with an everyday analogy.

  4. What is a side effect? Why do functional programmers avoid them?

  5. Why does input() need conversion before arithmetic?

  6. When would you use a while loop instead of a for loop?

  7. What is the difference between return and print()?

  8. Give one advantage and one disadvantage of lists, tuples, dictionaries, and sets.

  9. Why should you use with when opening files?

Tracing code#

  1. What is printed?

    total = 0
for i in range(1, 10, 3):
    if i % 2 == 0:
        continue
    total += i
print(total)

  2. What is printed, and why?

    a = [1, 2, 3]
b = a
c = a[:]
b.append(4)
print(a, c)

  3. What does {w: len(w) for w in "to be or not".split() if len(w) > 2} produce?

Writing code#

  1. Draw a flowchart and write a Python function water_bill(cubic_meters) with a minimum charge of ₱150 for the first 10 m³ and ₱25 per additional m³.

  2. Write a function that receives a list of scores and returns a dictionary with keys "average", "highest", "lowest", and "passed" (count of scores ≥ 75).

  3. Read data/grades.csv, skip rows with missing values, and print the name of the student with the highest final exam score.

  4. Write a class Wallet with an owner and a balance, and methods deposit() and spend() that rejects spending more than the balance.

Study Tips#

  • Re-run the code in each lesson and predict the output before running.

  • Redo the seatworks without looking at your previous answers.

  • Practice tracing loops with a table of variable values.

  • Draw flowcharts by hand; the examination may ask you to read or produce them.
