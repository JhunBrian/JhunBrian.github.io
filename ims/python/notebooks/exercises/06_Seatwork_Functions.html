Seatwork: Functions#

Learning Objective

Define and call user-defined functions; decompose a problem into procedures; use lambda, map, and filter.

Laboratory Exercise: GWA Toolkit#

Each subject is a tuple (code, grade, units), where grades follow the university scale (1.00 is highest, 3.00 is the lowest passing grade, 5.00 is failing).

subjects = [("DS112", 1.25, 3), ("MATH101", 1.75, 3), ("GE1", 1.50, 3), ("NSTP1", 1.00, 3), ("PE1", 2.00, 2)]

Task 1 — Small functions with return#

Write total_units(subjects) and gwa(subjects) (the units-weighted average of the grades). Both must return their results. Print the GWA to 3 decimals.

Expected output:

14
1.464

Task 2 — Default and keyword arguments#

Write is_passing(grade, passing=3.00) that returns True if the grade is at most passing. Call it for 2.75, 3.25, and 3.25 with passing=3.50.

Expected output:

True False True

Task 3 — Decomposition#

Write standing(gwa_value) that returns "Excellent" (≤ 1.50), "Very good" (≤ 2.00), "Good" (≤ 2.50), or "Fair". Then write report(name, subjects) that uses gwa() and standing() and returns a single string. Print the report for Ana.

Expected output:

Ana: GWA 1.464 (Excellent), 14 units

Task 4 — Sorting with a key function#

Print the subject codes sorted from best grade to worst; break ties by more units first. Use sorted() with a lambda key.

Expected output:

['NSTP1', 'DS112', 'GE1', 'MATH101', 'PE1']

Task 5 — map and filter#

Using filter and map with lambda:

  1. list the codes of subjects with a grade better than 1.50 (strictly less than 1.50);

  2. convert every grade to a percentage equivalent using percent = 100 - (grade - 1) * 12.5, rounded to 1 decimal.

Expected output:

['DS112', 'NSTP1']
[96.9, 90.6, 93.8, 100.0, 87.5]

Task 6 — Pure vs. impure#

The function below has a side effect. Rewrite it as a pure function curved(grades, bonus) that returns a new list and leaves the original unchanged. Show that original is unchanged after calling your function.

def curve(grades, bonus):
    for i in range(len(grades)):
        grades[i] = max(1.00, grades[i] - bonus)
    return grades

Expected output:

[1.0, 1.25, 1.5]
[1.25, 1.75, 2.0]

Task 7 — Reflection#

Answer in a Markdown cell:

  1. Why should gwa() return its value instead of printing it?

  2. Draw the decomposition tree of your Task 3 solution.

  3. Which of your functions are pure? Which paradigm(s) did you use in this seatwork?

Submission Requirements#

Submit one Jupyter Notebook containing all tasks in order. Each task should have:

  • the code that solves it;

  • the output produced by running the code; and

  • the Markdown answers to the questions asked.

Make sure the notebook runs from top to bottom without errors (Kernel → Restart & Run All) before submitting.
