Seatwork: Indexing, Selection, and Summaries#

Learning Objective

Select, filter, clean, and summarize data with pandas.

Laboratory Exercise: The DS112 Gradebook (data/grades.csv)#

Task 1 — loc and iloc#

Read the file with student_id as the index. Print (a) the name and final score of 2026-0010 using loc, (b) the first three rows and first three columns using iloc.

Expected output:

Jose 52.7
             name section  quiz
student_id                     
2026-0001     Ana    DS1A  56.8
2026-0002     Ben    DS1A  91.0
2026-0003   Carlo    DS1D  95.0

Task 2 — Filtering#

Print the number of students in DS1C, the names of students with both quiz and final ≥ 85, and the names in DS1A or DS1B with a final below 70.

Expected output:

6
['Carlo', 'Ella', 'Gina', 'Ivy', 'Wena']
['Ana', 'Hector', 'Jose', 'Uma', 'Grace']

Task 3 — Missing values#

Print the number of missing values per column, the names of students with any missing value, and the number of rows after dropna().

Expected output:

{'name': 0, 'section': 0, 'quiz': 0, 'lab': 1, 'midterm': 2, 'final': 0}
['Felix', 'Leo', 'Rafael']
33

Task 4 — Filling and updating#

Create clean = g.copy(). Fill missing midterms with the median midterm and missing labs with the mean lab (1 decimal). Then cap every final above 95 at 95 using loc. Print the number of missing values left and the maximum final.

Expected output:

0 95.0

Task 5 — Summaries#

Print the mean of each assessment (2 decimals), the count of students per section (sorted by section name), and the names of the top 3 by final.

Expected output:

{'quiz': 79.74, 'lab': 84.19, 'midterm': 75.74, 'final': 77.38}
{'DS1A': 10, 'DS1B': 5, 'DS1C': 6, 'DS1D': 15}
['Diana', 'Gina', 'Wena']

Task 6 — Method chaining#

In one chain: compute average as the mean of the four assessments, keep students with average ≥ 80, sort by average descending, and print the name and average (2 decimals).

Expected output:

              name  average
student_id                 
2026-0009      Ivy    94.82
2026-0023     Wena    94.80

2026-0005     Ella    92.68

Task 7 — Reflection#

Answer in a Markdown cell:

  1. When would you use iloc instead of loc?

  2. Was filling missing midterms with the median a good choice? Discuss one risk.

Submission Requirements#

Submit one Jupyter Notebook containing all tasks in order. Each task should have:

  • the code that solves it;

  • the output produced by running the code; and

  • the Markdown answers to the questions asked.

Make sure the notebook runs from top to bottom without errors (Kernel → Restart & Run All) before submitting.
