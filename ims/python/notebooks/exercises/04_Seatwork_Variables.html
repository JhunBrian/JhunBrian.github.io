Seatwork: Variables, Expressions, and Statements#

Learning Objective

Implement program logic in Python using variables, operators, type conversion, and f-strings, following PEP 8 conventions.

Laboratory Exercise: The Canteen Receipt#

Write each task in its own code cell. Use meaningful variable names and f-strings for output. Do not use input() — assign values directly.

Task 1 — Variables and arithmetic#

A student buys 2 cups of rice at ₱15, 1 chicken adobo at ₱80, and 1 buko juice at ₱40. Store each quantity and price in variables, then compute the subtotal.

Print it exactly as shown.

Expected output:

Subtotal: ₱150.00

Task 2 — Discount and change#

Students get a 10% discount. The student pays with a ₱200 bill. Compute the discount, the amount due, and the change.

Expected output:

Discount: ₱15.00
Amount due: ₱135.00
Change: ₱65.00

Task 3 — Breaking down the change#

Using // and %, express the change (as a whole number of pesos) in ₱50 bills, ₱20 bills, ₱5 coins, and ₱1 coins, using as few pieces as possible.

Expected output:

₱50 × 1, ₱20 × 0, ₱5 × 3, ₱1 × 0

Task 4 — Type conversion#

The cashier’s system stores values as text: price_text = "65.50" and qty_text = "3". Convert them and print the total, then print the type of each converted value.

Expected output:

Total: ₱196.50
<class 'float'> <class 'int'>

Task 5 — A formatted receipt#

Print a receipt with aligned columns using format specifiers (<, >, widths). Your output must match exactly:

Expected output:

================================
Item             Qty      Amount
--------------------------------
Rice               2       30.00
Chicken adobo      1       80.00
Buko juice         1       40.00
--------------------------------
Subtotal                  150.00
Discount (10%)            -15.00
TOTAL                     135.00
================================

Task 6 — Fix the style#

Rewrite this code so it follows PEP 8 and is easy to understand. The output must not change.

A=2;B=15;c=1;D=80
T=A*B+c*D
print(T)

Expected output:

110

Task 7 — Reflection#

Answer in a Markdown cell:

  1. Why does input() require type conversion before arithmetic?

  2. What is the difference between / and //? Give an example from the canteen problem.

  3. Which PEP 8 rules did you apply in Task 6?

Submission Requirements#

Submit one Jupyter Notebook containing all tasks in order. Each task should have:

  • the code that solves it;

  • the output produced by running the code; and

  • the Markdown answers to the questions asked.

Make sure the notebook runs from top to bottom without errors (Kernel → Restart & Run All) before submitting.
