Seatwork: Series and DataFrames#

Learning Objective

Create and use Series and DataFrames with essential pandas functionality.

Tasks#

Task 1 — Series and alignment#

Create two Series of quiz scores indexed by name and add them. Explain the missing values in Markdown.

import pandas as pd
quiz1 = pd.Series({"Ana": 18, "Ben": 15, "Carlo": 20})
quiz2 = pd.Series({"Ben": 17, "Carlo": 19, "Diana": 16})
print(quiz1 + quiz2)

Expected output:

Ana       NaN
Ben      32.0
Carlo    39.0
Diana     NaN
dtype: float64

Task 2 — Building a DataFrame#

Create a DataFrame df from the dictionary below and print its shape, its column names, and its dtypes.

data = {
    "item": ["Rice", "Chicken adobo", "Pork sinigang", "Pancit canton", "Buko juice"],
    "category": ["Staple", "Viand", "Viand", "Noodles", "Drink"],
    "price": [15, 80, 85, 60, 40],
    "sold": [120, 45, 38, 52, 60],
}

Expected output:

(5, 4)
['item', 'category', 'price', 'sold']
item          str
category      str
price       int64
sold        int64
dtype: object

Task 3 — New columns and sorting#

Add a revenue column (price × sold) and print the DataFrame sorted by revenue, highest first.

Expected output:

            item category  price  sold  revenue
1  Chicken adobo    Viand     80    45     3600
2  Pork sinigang    Viand     85    38     3230
3  Pancit canton  Noodles     60    52     3120
4     Buko juice    Drink     40    60     2400
0           Rice   Staple     15   120     1800

Set item as the index, then print (a) the price of "Pancit canton", (b) the sold column as a Series, and (c) the table without the category column.

Task 5 — describe#

Print the summary statistics of the numeric columns, rounded to 1 decimal.

Expected output:

       price   sold  revenue
count    5.0    5.0      5.0
mean    56.0   63.0   2830.0
std     29.0   32.9    721.6

Task 6 — Reflection#

Answer in a Markdown cell:

  1. How is a Series different from a NumPy array?

  2. Why does drop() not change menu unless you assign the result?

Submission Requirements#

Submit one Jupyter Notebook containing all tasks in order. Each task should have:

  • the code that solves it;

  • the output produced by running the code; and

  • the Markdown answers to the questions asked.

Make sure the notebook runs from top to bottom without errors (Kernel → Restart & Run All) before submitting.
