Seatwork: One-Dimensional Arrays#

Learning Objective

Apply indexing, masks, vectorized arithmetic, and aggregation on 1D arrays to simple problems.

Laboratory Exercise: Daily Rainfall#

import numpy as np
rain = np.array([0.0, 2.5, 12.0, 30.5, 45.0, 8.0, 0.0, 0.0, 3.5, 60.0, 72.5, 15.0, 0.0, 1.0])   # mm, 14 days

Task 1 — Indexing and slicing#

Print the rainfall on day 1, the last day, the second week (days 8–14), and every other day starting from day 1.

Expected output:

0.0 1.0
[ 0.   3.5 60.  72.5 15.   0.   1. ]
[ 0.  12.  45.   0.   3.5 72.5  0. ]

Task 2 — Aggregations#

Print the total, average (2 decimals), maximum, and the day number (1-based) of the maximum.

Expected output:

250.0 17.86 72.5 11

Task 3 — Boolean masks#

Print (a) the readings of rainy days (≥ 1 mm), (b) the number of dry days (0 mm), and (c) the day numbers of heavy rain (≥ 30 mm).

Expected output:

[ 2.5 12.  30.5 45.   8.   3.5 60.  72.5 15.   1. ]
4
[ 4  5 10 11]

Task 4 — Vectorized transformation#

Convert the readings to inches (1 inch = 25.4 mm, 2 decimals) and label each day "Heavy" (≥ 30), "Light" (> 0), or "Dry" using nested np.where.

Expected output:

[0.   0.1  0.47 1.2  1.77 0.31 0.   0.   0.14 2.36 2.85 0.59 0.   0.04]
['Dry' 'Light' 'Light' 'Heavy' 'Heavy' 'Light' 'Dry' 'Dry' 'Light' 'Heavy'
 'Heavy' 'Light' 'Dry' 'Light']

Task 5 — Normalization#

Compute the min–max normalized values (2 decimals) and the z-scores (2 decimals).

Expected output:

[0.   0.03 0.17 0.42 0.62 0.11 0.   0.   0.05 0.83 1.   0.21 0.   0.01]
[-0.76 -0.65 -0.25  0.54  1.15 -0.42 -0.76 -0.76 -0.61  1.79  2.32 -0.12
 -0.76 -0.71]

Task 6 — Views vs. copies#

Take week1 = rain[:7], set week1[0] = 99, and print rain[0]. Then restore the value and repeat using .copy(). Explain the difference in Markdown.

Expected output:

99.0
0.0

Task 7 — Reflection#

Answer in a Markdown cell:

  1. Rewrite Task 3(c) with a for loop. Which version is clearer?

  2. Identify the filter, map, and reduce steps in Task 4.

Submission Requirements#

Submit one Jupyter Notebook containing all tasks in order. Each task should have:

  • the code that solves it;

  • the output produced by running the code; and

  • the Markdown answers to the questions asked.

Make sure the notebook runs from top to bottom without errors (Kernel → Restart & Run All) before submitting.
