Seatwork: Reading Data and Text Preprocessing#

Learning Objective

Read data files with pandas and preprocess text data in several programming styles.

Laboratory Exercise: Preprocessing Hotel Reviews#

This seatwork continues the course’s text preprocessing notebook. The file data/reviews.csv contains 10,000 hotel reviews in the column reviews.text. Before text can be analyzed, it is preprocessed: lowercased, stripped of punctuation, and split into words.

You will do the same preprocessing in an imperative, a functional, and a pandas (declarative) style, and check that all three agree.

Task 1 — Read the data#

Read the file, keep only the id and reviews.text columns, rename reviews.text to text, and print the shape and the first review.

Expected output:

(10000, 2)
This hotel was nice and quiet. Did not know, there was train track near by. But it was only few train passed during our stay. Best Western changed hotel classification. The Plus category are not the same as before.

Task 2 — Imperative lowercasing#

Without using .lower(), convert the first 5 reviews to lowercase using ord() and chr(): uppercase letters A–Z have codes 65–90, and adding 32 gives the lowercase letter. Store the results in a list imperative_lower and print the first one.

Expected output:

this hotel was nice and quiet. did not know, there was train track near by. but it was only few train passed during our stay. best western changed hotel classification. the plus category are not the same as before.

Task 3 — Functional preprocessing#

Write pure functions lowercase(text), remove_punctuation(text) (keep letters, digits, and spaces), and tokenize(text), then a function preprocess(text) that composes them. Apply it with map to the first 5 reviews and print the first 8 tokens of the first review.

Expected output:

['this', 'hotel', 'was', 'nice', 'and', 'quiet', 'did', 'not']

Task 4 — pandas preprocessing#

Using .str methods and a regular expression, preprocess all 10,000 reviews into a column tokens. Check that the first 5 rows equal your functional results, then print the average number of tokens per review (1 decimal).

Expected output:

True
120.5

Task 5 — Word frequencies#

Explode the tokens into one word per row, remove the stop words below and words shorter than 3 letters, and print the 8 most common words.

stop = {"the", "and", "was", "were", "for", "with", "our", "but", "this", "that", "had", "not",
        "you", "they", "are", "there", "room", "hotel", "stay", "very", "would", "have", "from",
        "your", "all", "thank", "them", "what", "when", "will", "just", "also", "been", "one", "here", "more"}

Expected output:

tokens
staff        6250
great        5909
clean        4222
breakfast    4174
nice         3919
again        3894
time         3837
rooms        3737
Name: count, dtype: int64

Task 6 — Write the result#

Save a CSV with columns id and n_tokens (number of tokens) for all reviews. (Write it to your own folder.)

Task 7 — Reflection#

Answer in a Markdown cell:

  1. Compare the three styles in Tasks 2–4 for readability, speed, and ease of testing.

  2. Which style would you use for 10 million reviews? Why?

Submission Requirements#

Submit one Jupyter Notebook containing all tasks in order. Each task should have:

  • the code that solves it;

  • the output produced by running the code; and

  • the Markdown answers to the questions asked.

Make sure the notebook runs from top to bottom without errors (Kernel → Restart & Run All) before submitting.
