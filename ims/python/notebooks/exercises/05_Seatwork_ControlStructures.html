Seatwork: Control Structures#

Learning Objective

Implement program logic using conditional statements and loops.

Laboratory Exercise: Barangay Health Monitor#

A barangay health worker records body temperatures and ages of residents during a health check.

Task 1 — Classify a temperature#

Write code that classifies a temperature t (°C):

Range

Classification

below 35.0

Hypothermia

35.0 – 37.4

Normal

37.5 – 38.9

Fever

39.0 and above

High fever

Test it with 34.2, 36.8, 37.5, and 39.4 using a for loop.

Expected output:

34.2 °C → Hypothermia
36.8 °C → Normal
37.5 °C → Fever
39.4 °C → High fever

Task 2 — Counting and averaging#

Given the readings below, use one loop to compute: the average temperature (2 decimals), the number of fever cases (≥ 37.5), and the highest reading.

readings = [36.5, 37.8, 36.9, 39.2, 37.1, 38.0, 36.4, 35.9, 37.6, 36.7]

Expected output:

Average: 37.21 °C
Fever cases: 4
Highest: 39.2 °C

Task 3 — Priority with combined conditions#

Residents are priority if they have a fever (≥ 37.5) and are either below 5 or at least 60 years old. Print the priority residents.

residents = [("Lito", 67, 37.9), ("Ana", 4, 37.2), ("Ben", 30, 38.4), ("Cora", 3, 38.1), ("Dado", 72, 36.6)]

Expected output:

PRIORITY: Lito (67 yrs, 37.9 °C)
PRIORITY: Cora (3 yrs, 38.1 °C)

Task 4 — Input validation with while#

Simulate reading temperatures typed by the health worker. Keep reading values from typed until a valid reading between 30 and 45 is found. Print each rejected value. (Use an index variable, as in the lesson — no input().)

typed = ["3.65", "365", "-1", "36.5"]

Expected output:

Rejected: 3.65
Rejected: 365.0
Rejected: -1.0
Accepted: 36.5

Task 5 — Search with break#

Find the first resident with a high fever (≥ 39.0) in residents from Task 3. If none is found, print "No high fever". Use break and a loop else.

Expected output:

No high fever

Task 6 — Nested loops: a schedule grid#

Print a vaccination schedule grid for 3 puroks and 4 weeks, where each cell shows P<purok>-W<week>, exactly as below.

Expected output:

P1-W1  P1-W2  P1-W3  P1-W4
P2-W1  P2-W2  P2-W3  P2-W4
P3-W1  P3-W2  P3-W3  P3-W4

Task 7 — Reflection#

Answer in a Markdown cell:

  1. In Task 1, why does the order of the elif conditions matter?

  2. When did you use for, and when while? Why?

  3. Draw the flowchart for Task 4.

Submission Requirements#

Submit one Jupyter Notebook containing all tasks in order. Each task should have:

  • the code that solves it;

  • the output produced by running the code; and

  • the Markdown answers to the questions asked.

Make sure the notebook runs from top to bottom without errors (Kernel → Restart & Run All) before submitting.
