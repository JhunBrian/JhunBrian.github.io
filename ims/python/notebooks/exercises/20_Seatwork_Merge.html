Seatwork: Merge, Join, and Concatenate#

Learning Objective

Combine datasets with concatenation, merges, and joins.

Tasks#

Task 1 — Merge types#

Merge the two tables below with each of inner, left, right, and outer, and print the number of rows of each result.

import pandas as pd
students = pd.DataFrame({"id": [1, 2, 3, 4], "name": ["Ana", "Ben", "Carlo", "Diana"]})
clubs = pd.DataFrame({"id": [1, 1, 3, 5], "club": ["Chess", "Data Sci", "Dance", "Choir"]})

Expected output:

inner 3
left 5
right 4
outer 6

Task 2 — Indicator#

Using an outer merge with indicator=True, print the names of students without a club and the IDs of club records without a student.

Expected output:

['Ben', 'Diana']
[5]

Task 3 — Revenue with merge#

Merge canteen_sales.csv with menu.csv on item_code (validate="many_to_one"), compute revenue = qty × price, and print total revenue per category, highest first.

Expected output:

category
Viand      99075
Drink      36850
Noodles    29280
Dessert    24180
Snack      20545
Staple     17550
Name: revenue, dtype: int64

Task 4 — Concatenate#

Split full into the Main and Annex rows, then put them back together with pd.concat and keys=["Main", "Annex"]. Print the number of rows and the revenue of each part using the new index level.

Expected output:

2450
Annex     83655
Main     143825
Name: revenue, dtype: int64

Task 5 — Different key names#

A supplier table names its key code. Merge it with total units per item and print the items whose units are below the reorder level.

supplier = pd.DataFrame({"code": ["RICE", "ADOBO", "HALO", "COFFEE"], "reorder_level": [2000, 900, 600, 800]})

Expected output:

  item_code   qty  reorder_level
0     ADOBO   687            900
1    COFFEE   639            800
2      HALO   372            600
3      RICE  1170           2000

Task 6 — Reflection#

Answer in a Markdown cell:

  1. Which merge type keeps every sale even if its item is missing from the menu?

  2. What does validate="many_to_one" protect you from?

Submission Requirements#

Submit one Jupyter Notebook containing all tasks in order. Each task should have:

  • the code that solves it;

  • the output produced by running the code; and

  • the Markdown answers to the questions asked.

Make sure the notebook runs from top to bottom without errors (Kernel → Restart & Run All) before submitting.
