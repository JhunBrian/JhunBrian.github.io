# How to use this book

This is your reading and practice companion for **DS112 — Computer Programming**. Work through the lessons in order, or use the navigation to revisit a topic.

## Find your way

- **Course navigation** on the left lists lessons by module. Seatworks and activities sit directly below their related lesson. On a small screen, use the menu button to open it.
- **On this page** lists the headings of the current page.
- **Search** finds terms across the book, including code.
- **Previous and next** links at the bottom follow the reading order.

## Lessons, seatworks, and activities

| Page | Label in the navigation | Purpose |
| ---- | ----------------------- | ------- |
| **Lesson** | topic title | explanations, analogies, diagrams, and runnable examples |
| **Seatwork** | *Seatwork · …* | guided practice with **expected outputs** so you can check your work; used in class and laboratory sessions |
| **Graded activity** | *Activity · …* | an assignment, portfolio, or project from the syllabus, with deliverables and the assessment rubric |

Every page ends with a **References** section listing the sources used and suggested further reading.

## Read, experiment, reflect

Read the explanation, predict what an example will do, then run and modify it in your own notebook. The website displays notebook content; to run Python, download the notebook from the page toolbar and open it in Jupyter. Download the [datasets](datasets.md) into a `data` folder next to your notebooks.

```{tip}
Use the theme button in the toolbar to switch between light and dark reading modes. Full-screen mode gives long examples more room.
```
