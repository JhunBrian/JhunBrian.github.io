# Datasets

The lessons, seatworks, and activities use the files below. Download them into a folder named `data` next to your notebook so that paths such as `data/grades.csv` work.

| File | Used in | Description |
| ---- | ------- | ----------- |
| {download}`grades.csv <notebooks/data/grades.csv>` | files, NumPy, pandas | 36 students, 4 sections, quiz/lab/midterm/final scores, with a few missing values (**synthetic**) |
| {download}`menu.csv <notebooks/data/menu.csv>` | pandas | canteen menu: item codes, names, categories, prices (**synthetic**) |
| {download}`canteen_sales.csv <notebooks/data/canteen_sales.csv>` | pandas | one month of canteen order lines for two branches (**synthetic**) |
| {download}`weather.csv <notebooks/data/weather.csv>` | pandas | daily temperature, rainfall, and humidity for three stations (**synthetic** — not real observations) |
| {download}`advertising_synthetic.csv <notebooks/data/advertising_synthetic.csv>` | revisiting paradigms | TV advertising budget vs. sales for 200 markets (**synthetic**, modeled on the ISLR *Advertising* data) |
| {download}`reviews.csv <notebooks/data/reviews.csv>` | dictionaries, text data | 10,000 hotel review texts (provided with the course materials) |
| {download}`sample_data.xlsx <notebooks/data/sample_data.xlsx>` | reading Excel files | loan-application toy dataset (provided with the course materials) |

```{note}
The synthetic datasets were generated with a fixed random seed for teaching purposes. They do not describe real students, businesses, or weather.
```
