Objects and Classes — Coding Exercise#

Learning Objective

This exercise practices defining classes with instance and class attributes, writing methods, creating and using objects, and combining your own classes with classes from Python’s standard library (datetime, statistics, collections).

Laboratory Exercise: Course Gradebook#

Scenario#

Your instructor wants a small program to keep track of student scores in a course. Each student has a name, a student ID, and a list of scores. The course has a code, a start date, and a list of enrolled students.

Letter grades are assigned from a student’s average:

Task 1 — The Student Class#

Create a class Student with:

  • a class attribute school equal to "USTP";

  • a constructor that receives name and student_id and creates the instance attributes name, student_id, and an empty list scores.

Create two students and print their attributes:

ana = Student("Ana", "2026-001")
ben = Student("Ben", "2026-002")

print(ana.name, ana.student_id, ana.scores, ana.school)
print(ben.name, ben.student_id, ben.scores, ben.school)

Expected output:

Ana 2026-001 [] USTP
Ben 2026-002 [] USTP

Task 2 — Methods#

Add the following methods to Student:

Method

Behavior

add_score(score)

appends a score to the student’s list

average()

returns the mean of the scores, or 0 if there are none

letter()

returns the letter grade using the table in the scenario (call average() inside it)

Test:

for score in (92, 88, 95):
    ana.add_score(score)

print(round(ana.average(), 2), ana.letter())
print(ben.average(), ben.letter())

Expected output:

91.67 A
0 F

Task 3 — Class vs. Instance Attributes#

Run the following and explain the output in a Markdown cell:

Student.school = "USTP-CDO"
print(ana.school, ben.school)

ana.school = "Another University"
print(ana.school, ben.school, Student.school)
print(vars(ana))

Expected output:

USTP-CDO USTP-CDO
Another University USTP-CDO USTP-CDO
{'name': 'Ana', 'student_id': '2026-001', 'scores': [92, 88, 95], 'school': 'Another University'}

Why did changing Student.school affect both objects, but changing ana.school affected only Ana? What does vars(ana) reveal?

Task 4 — The Course Class#

Create a class Course whose constructor receives a code and a start date (a datetime.date object) and starts with an empty list of students.

Add the methods:

Method

Returns

enroll(student)

nothing; adds the Student object to the course

averages()

a dictionary {name: average rounded to 2 decimals}

top_student()

the name of the student with the highest average

Use this data:

from datetime import date

ds212 = Course("DS212", date(2026, 8, 10))

data = {
    "Ana": [92, 88, 95],
    "Ben": [78, 74, 80],
    "Carlo": [85, 83, 90],
    "Diana": [70, 65, 72],
    "Ella": [91, 89, 94],
}

for i, (name, scores) in enumerate(data.items(), start=1):
    student = Student(name, f"2026-{i:03d}")
    for score in scores:
        student.add_score(score)
    ds212.enroll(student)

print(ds212.averages())
print(ds212.top_student())

Expected output:

{'Ana': 91.67, 'Ben': 77.33, 'Carlo': 86.0, 'Diana': 69.0, 'Ella': 91.33}
Ana

Task 5 — Using the Standard Library#

Add three more methods to Course, each using a standard-library class or module:

Method

Use

Returns

grade_distribution()

collections.Counter

a dictionary of letter → count, sorted by letter

median_average()

statistics.median

the median of all students’ (unrounded) averages

week_number(day)

datetime.date arithmetic

the course week that day falls in (the start date is week 1)

Test:

print(ds212.grade_distribution())
print(ds212.median_average())
print(ds212.week_number(date(2026, 8, 10)))
print(ds212.week_number(date(2026, 9, 14)))

Expected output:

{'A': 2, 'B': 1, 'C': 1, 'F': 1}
86.0
1
6

Hint: subtracting two date objects produces a timedelta, which has a .days attribute.

Task 6 — Reflection#

Answer in a Markdown cell:

  1. Which attributes in your solution are class attributes, and which are instance attributes? Why?

  2. Which of your methods are commands (they change the object) and which are queries (they only return information)?

  3. Counter, date, and timedelta are classes too. Name one method or attribute you used from each.

Submission Requirements#

Submit one Jupyter Notebook containing all tasks in order. Each task should have:

  • the code that solves it;

  • the output produced by running the code; and

  • the Markdown answers to the questions asked.

Make sure the notebook runs from top to bottom without errors (Kernel → Restart & Run All) before submitting.
