Python Review I & II — Coding Exercise#

Learning Objective

This exercise combines the two Python review weeks in the syllabus. Review I focuses on syntax, variables, data types, expressions, operators, and I/O, while Review II adds conditionals, loops, functions, and basic modules.

Laboratory Exercise: Student Performance Analyzer#

Scenario#

You are asked to create a simple Python program that processes a student’s scores and determines their academic performance.

For this exercise, a student has:

student_name = "Maria Santos"

quiz_score = 85
activity_score = 92
exam_score = 78

The weights are:

Component

Weight

Quiz

30%

Activity

30%

Exam

40%

A final grade of 70 or higher is considered passing.

Task 1 — Variables and Expressions#

Create variables containing the student’s:

  • name

  • quiz score

  • activity score

  • exam score

Calculate the weighted final grade using:

final_grade = quiz × 0.30 + activity × 0.30 + exam × 0.40

Store the result in a variable called:

final_grade

Display:

Student: Maria Santos
Final Grade: 83.50

Use an f-string and format the grade to two decimal places.

Task 2 — User Input#

Replace the hard-coded values with input().

Example interaction:

Enter student name: Maria Santos
Enter quiz score: 85
Enter activity score: 92
Enter exam score: 78

Remember that input() returns a string, so the scores must be converted to an appropriate numeric type.

Your program should still calculate and display the final grade.

Task 3 — Inspect Your Data#

Before continuing, use type() to inspect some of your variables.

print(type(student_name))
print(type(quiz_score))
print(type(final_grade))

Answer in a Markdown cell:

Why is student_name a different data type from the scores?

Why do values entered using input() need to be converted before performing arithmetic?

This completes the main concepts from Python Review I.

Task 4 — Conditional Statements#

Determine whether the student passed.

final_grade >= 70 → Passed
final_grade < 70  → Failed

Expected output:

Student: Maria Santos
Final Grade: 83.50
Status: Passed

Then add a performance classification:

Final Grade

Classification

90–100

Excellent

80–89.99

Very Good

70–79.99

Satisfactory

Below 70

Needs Improvement

Use if, elif, and else.

Task 5 — Convert the Program into a Function#

Move your grade calculation into:

def calculate_grade(quiz, activity, exam):
    # your code

The function must return the calculated grade rather than print it.

Your main program should therefore be able to do:

final_grade = calculate_grade(85, 92, 78)

print(final_grade)

Then create another function:

def determine_status(final_grade):
    # your code

It should return either:

Passed

or:

Failed

Task 6 — Process Multiple Students#

You are now given multiple students:

students = [
    ["Ana", 85, 90, 88],
    ["Ben", 65, 70, 60],
    ["Carlo", 92, 89, 95],
    ["Diana", 70, 75, 73],
    ["Ella", 55, 60, 58]
]

Each inner list follows:

[name, quiz, activity, exam]

Use a for loop to process every student.

Your existing function should be reused:

calculate_grade(...)

Do not manually calculate the grade separately for every student.

Expected output should resemble:

Ana       87.70   Passed
Ben       64.50   Failed
Carlo     92.30   Passed
Diana     72.70   Passed
Ella      57.70   Failed

Task 7 — Class Statistics#

Using a loop, determine:

Number of students: 5
Passed: 3
Failed: 2
Class Average: _____

Do not hard-code these answers.

Your program must calculate them from students.

Then determine the highest final grade in the class.

Task 8 — Input Validation#

Modify the program so that a score outside the valid range is rejected.

Valid scores are:

0 <= score <= 100

Example:

Enter quiz score: 125
Invalid score. Enter a value from 0 to 100.

Enter quiz score: -20
Invalid score. Enter a value from 0 to 100.

Enter quiz score: 85

Use a while loop so that the program keeps asking until a valid score is entered.

Create:

def get_valid_score(label):
    # your code

Example:

quiz = get_valid_score("Quiz")
activity = get_valid_score("Activity")
exam = get_valid_score("Exam")
